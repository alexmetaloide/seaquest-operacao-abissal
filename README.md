# Seaquest — Operação Abissal

Uma homenagem jogável aos jogos de fliperama submarinos. Navegue por um oceano de neon, desvie de criaturas, resgate seis mergulhadores e volte à superfície para contabilizar os pontos.

## Como jogar

- **Mover:** setas ou `W A S D`
- **Disparar:** `Espaço`
- **Iniciar/recomeçar:** `Enter`
- **Celular:** controles na tela

Cada mergulhador resgatado vale 500 pontos. Leve a tripulação de volta à superfície para somar mais 500 pontos por pessoa. O oxigênio se recupera na superfície. A melhor pontuação fica salva neste navegador.

O jogo roda diretamente no navegador, sem instalação ou dependências de build.

## Publicação

O workflow em `.github/workflows/pages.yml` publica o site automaticamente a cada atualização da branch `main`.
